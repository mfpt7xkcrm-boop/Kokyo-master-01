# 公共 Master — 2学期中間テスト対策

GitHub Pagesでそのまま公開できる、HTML/CSS/JavaScript製の静的な学習アプリです。ビルド、外部API、課金は不要です。

## 使い方

1. GitHubで公開用のリポジトリ（例 `kokyo-master`）を新規作成します。
2. `index.html`、`style.css`、`app.js`、`data.js` をリポジトリのルートにアップロードします。
3. **Settings → Pages → Build and deployment → Deploy from a branch** で `main` / `/(root)` を選び、保存します。
4. GitHub Pagesの公開URLから開いてください（反映には少し時間がかかることがあります）。

ローカルでは `index.html` を開いても動きます。正式な動作確認は静的HTTPサーバーで行ってください（例: `python3 -m http.server 8000`）。

## 機能

- ダッシュボード：習得数、回答済み問題、弱点数
- 一問一答・4択、記述（表記ゆれ一部対応、手動採点の修正）
- 4択と記述を交互に出す模擬テスト・終了後の解説
- 間違えた問題の優先復習、分野別フィルタ
- 用語カード
- `localStorage`への自動保存、JSONによるエクスポート/インポート、記録リセット

## 問題データ

`data.js` の `RAW` に `分野|設問|正答|解説|別解` の順で１行ずつ追加できます。区切り記号の `|` は問題・解説本文内には使わないでください。問題IDは行番号から自動生成しています。**問題を途中に挿入・並べ替えすると保存済みの習得状況が別の問題に紐づく**ため、問題は末尾に追加するか、ID方式を変更してから運用してください。

出題範囲はワークノート p.30–45、p.49–50、教科書 p.36–49、p.54–57 の写真をもとにした独自問題です。学校の試験問題の再現・出題保証ではありません。著作物の長文転載を避けています。実際の正解表記は授業の資料も確認してください。

## 制限

- ログイン・端末間自動同期はありません。端末ごとに記録が残ります。
- ブラウザのサイトデータ削除やプライベートブラウズでは学習履歴が消える場合があります。定期的にエクスポートしてください。
- 記述の自動判定は文字列の一致を基本としており、意味が正しくても不正解となることがあります。手動修正可能です。
- 模擬テストは**現段階では時間制限なし**です。時間制限・本番風の長文問題は今後の拡張候補です。
